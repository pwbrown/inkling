# typing-game (working title)

A browser-based, offline-first typing game inspired by *Typer Shark*. Targets drift in from the right carrying words, characters, digits or symbols, and you type them before they reach you. What makes it different is that **you choose exactly which keys to practice**, and the game builds all of its content from only those keys, so it grows with you as you learn.

No servers and no analytics. Everything stays on your device.
